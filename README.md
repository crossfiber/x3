# Golf at X3 Fort Myers: a concept proposal

A single page prepared by Ryan Hogan showing what a golf performance program could look
like running inside X3 Performance and Physical Therapy, 13050 Metro Parkway, Fort Myers.

**This is a concept proposal.** It is not published, endorsed or operated by X3, and no
partnership currently exists. Facility details, the academy list, the Google rating and
the X3 marks are reproduced from x3ppt.com for the purpose of this proposal and remain
the property of X3 Performance and Physical Therapy. The page is set to `noindex` and is
not intended for public search.
